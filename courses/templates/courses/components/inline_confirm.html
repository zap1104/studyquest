The panel is revealed by [data-confirm-trigger] and hidden by [data-confirm-cancel]. Escape also cancels. Without JS the panel stays hidden, so the destructive action is simply not reachable. This block uses {% comment %} rather than {# #} deliberately: Django's {# #} is single-line only, and a multi-line one is NOT recognised -- it leaks into the rendered page as visible text.
